# Configuration values for developers
To build a new optimization simulation model using the three classes (UCData, UCDicts, UCVars) and two functions (make_grb_model, output_result) that make up this tool, options are provided for the handover of dictionary type data, decision variables, objective functions, constraint expressions.
Note that if the following settings are changed from the defaults, error-free operation is not guaranteed.

- [Dictionary type data creation options](02_dicts.md)
- [Decision variable options](03_variables.md)
- [Objective function options](04_objective.md)
- [Constraint expression options](05_constraints.md)
- [Decision variable inheritance options](06_inheritance.md)
