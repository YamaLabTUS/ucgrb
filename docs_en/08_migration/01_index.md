# Migration from previous versions

The format of the input files (power system data CSV files and the configuration file) has changed in some ucgrb version upgrades.
The procedures for using input files from a previous version with a newer version are listed below by source and target version.

| From | To | Modification required? | Procedure |
| :--- | :- | :--------------------- | :-------- |
| v5   | v7 | Generally no (the name column must be checked; items must be added only when using the ΔkW-value version) | [Migration from v5 to v7 (how to modify the input files)](02_v5_to_v7.md) |
