# 旧バージョンからの移行方法

ucgrbのバージョンアップに伴い、入力ファイル（電力系統データCSVファイル・設定ファイル）の形式が変更されたことがある。
旧バージョンで用いていた入力ファイルを新しいバージョンで利用する際の手順を、移行元・移行先のバージョンごとに以下に示す。

| 移行元 | 移行先 | 修正の要否 | 手順 |
| :----- | :----- | :--------- | :--- |
| v5     | v7     | 原則不要（name列の確認が必須。ΔkW価値考慮版を利用する場合のみ項目追加） | [v5からv7への移行（入力ファイルの変更方法）](02_v5_to_v7.md) |

- [v5からv7への移行（入力ファイルの変更方法）](02_v5_to_v7.md)
